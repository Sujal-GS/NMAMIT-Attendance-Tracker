Install NMAMIT Tracker 📲

Install NMAMIT Attendance Tracker as a native mobile app on your phone. No App Store needed!

⚡ 1-Tap Home Screen Access 📴 Works 100% Offline 🚀 Full-Screen Native UI
🍏 For iPhone / iPad (Safari)
1 Tap the Share button (square with arrow ) in Safari's bottom toolbar.
2 Scroll down and tap Add to Home Screen.
3 Tap Add in the top right corner. The NMAMIT icon will appear on your home screen!
🤖 For Android / Chrome
1 Tap the three dots (⋮) menu in Chrome's top-right corner.
2 Select Install app or Add to Home screen.
